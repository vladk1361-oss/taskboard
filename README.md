# Список задач на C++

Мой небольшой учебный проект на C++. Это простой список задач для консоли на русском языке.

Можно добавить задачу, посмотреть список, удалить одну задачу или очистить весь список. Задачи хранятся только пока программа открыта.

## Запуск

В терминале VS Code:

```powershell
cmake -S . -B build
cmake --build build
.\build\taskboard.exe
```

## Что использовал

- `vector` для списка задач;
- `string` для текста задачи;
- `while` и `if` для меню;
- ввод и вывод через `cin` и `cout`.
